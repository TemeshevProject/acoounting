# acoounting

Приоритизация процессов бухгалтерии для оптимизации и автоматизации: см. `prioritization/priority_processes.md`.

Пересчёт рейтинга: `python3 prioritization/build_priorities.py <Карта_процессов_бухгалтерии.html>` (нужен `openpyxl`).

Презентация проекта: `presentation/accounting_processes_deck.pptx` (сборка: `python3 presentation/build_deck.py`, нужен `python-pptx`).

Презентация в брендбуке Sergek Group: `presentation/accounting_processes_deck_brand.pptx` (сборка: `python3 presentation/build_deck_brand.py`; логотипы, элемент «волна» и шрифты Golos Text лежат в `presentation/assets/`).
